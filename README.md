# The Fabric of a Dream

Sleep Textile Studio — a browser-based research prototype for creative authorship of sleep data through digital knitting.

## Getting started

Open `index.html` in a browser, or use GitHub Pages after enabling it. Choose a synthetic night or import Oura sleep JSON or a supported CSV. Select sleep stages, heart rate, HRV, stage transitions or stage composition (depending on available data), then customize patterns, colors, motifs and dimensions.

## Fabrication

Export a production PNG or test swatch. The four-stage and four-level palettes can use up to five colors including the background; the binary mode uses two. Import the bitmap into Customist Studio and configure yarn carriers, jacquard structure, gauge, cast-on and bind-off. Export machine instructions there. Physical knitting and actual Oura exports have not yet been validated. Test swatches first.

## Privacy

Data is processed locally in the browser. Do not commit real participant data or personal exported patterns to this public repository. The example JSON is entirely synthetic. This is an artistic research prototype, not a medical device.

## Hosting

Enable GitHub Pages under Settings > Pages, deploy from `main` and `/ (root)`.
